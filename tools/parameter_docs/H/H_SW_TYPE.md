# Swashplate Type (H_SW_TYPE)

## Description
Defines the physical layout of the swashplate servos (e.g., 120-degree CCPM vs. 90-degree).
*   **0: H3 Generic (3 servos)**
*   **1: H1 (Non-CCPM)**
*   **3: H3_120 (Standard 120-degree layout)**
